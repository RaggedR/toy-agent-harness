# A Toy Agent Harness

Running a minimal autonomous agent harness on a Claude Max subscription — the
essay, the plan, and the working toy code.

- `toy-harness.tex` / `.pdf` — **The Toy Harness** (essay).
- `max-plan.tex` / `.pdf` — running it on a Claude Max subscription.
- `toy_harness.py`, `toy_harness_max.py` — the harness code (reads
  `ANTHROPIC_API_KEY` from the environment; no credentials committed).
